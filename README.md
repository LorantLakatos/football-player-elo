# football-player-elo

An Elo-based rating system for individual football players, designed to evaluate player performance by considering match difficulty and other relevant factors to build a data-driven player ranking.

## About the Project

This is a personal passion project that combines my interest in football, data analysis, and programming. The goal is to explore whether an Elo-based approach can be adapted to individual football players and provide meaningful insights into their performances.

## Project Status

**Work in progress.** The project is still under active development, and the rating system is not yet fully refined. Some features may be incomplete, and the current results should be considered experimental. The methodology, code, and overall functionality will continue to evolve as the project develops.

## Motivation

I started this project to explore football analytics in more depth while improving my programming and data analysis skills. It is an ongoing personal project driven by curiosity and an interest in finding new ways to evaluate football players using data.
